# Mélység

Fúrókapszulával a Föld középpontja felé

Játszható a böngészőben: https://buhallamate-del.github.io/ kéreg, köpeny, olvadt vasmag – a PREM földmodell hőmérsékletével, nyomásával és nehézségi gyorsulásával. Fejlesztések, valódi tudományos napló, heti mélységverseny, és ami a közepén vár.:Melyseg/

Egyetlen fájl (`index.html`), a mentés a böngésző helyi tárhelyén él. A heti verseny egy nyilvános MQTT üzenetközvetítőn (HiveMQ) megy át; a könyvtár: `vendor/mqtt/` (MIT licenc). A játék a szerző többi játékával közös naplót vezet (multiverzum).
